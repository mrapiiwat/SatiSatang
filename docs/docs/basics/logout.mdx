# การออกจากระบบ

เพื่อความปลอดภัยของข้อมูลทางการเงินของคุณ เราแนะนำให้คุณออกจากระบบทุกครั้งเมื่อเลิกใช้งานบนอุปกรณ์สาธารณะ

### ขั้นตอนการออกจากระบบ

1.  **เปิดเมนูหลัก:** คลิกที่ปุ่มเมนู (สัญลักษณ์ขีดสามขีด) บริเวณมุมขวาบนของหน้าจอ
2.  **เลือกเมนูออกจากระบบ:** เลื่อนลงมาที่ด้านล่างสุดของแถบเมนู คุณจะพบกับปุ่ม **"ออกจากระบบ"**
3.  **ยืนยันการทำงาน:** ระบบจะทำการเคลียร์ข้อมูลเซสชันของคุณและนำคุณกลับสู่หน้าเริ่มต้นทันที

![เมนู Sidebar และปุ่มออกจากระบบ](/img/screenshot/Screenshot%202569-04-28%20at%2020.49.24.png)

:::info สิ่งที่จะเกิดขึ้นเมื่อออกจากระบบ
- ข้อมูลการเข้าสู่ระบบในเบราว์เซอร์ปัจจุบันจะถูกลบออก
- หากคุณต้องการกลับมาใช้งานอีกครั้ง คุณจะต้องทำการเข้าสู่ระบบใหม่
- ข้อมูลทางการเงินทั้งหมดของคุณจะถูกบันทึกไว้อย่างปลอดภัยบนเซิร์ฟเวอร์ และไม่สูญหายจากการออกจากระบบ
:::

## ปัญหาที่พบบ่อยเกี่ยวกับการออกจากระบบ

| ปัญหา | วิธีแก้ไข |
| :--- | :--- |
| **หาปุ่มออกจากระบบไม่เจอ** | ปุ่มจะอยู่ที่ด้านล่างสุดของเมนู Sidebar ให้ลองเลื่อนหน้าจอลงมาด้านล่างสุด |
| **กดออกจากระบบแล้วยังอยู่ที่หน้าเดิม** | ลองรีเฟรชหน้าจอ (Refresh) หรือล้างแคชของเบราว์เซอร์แล้วลองอีกครั้ง |
| **ต้องการออกจากระบบทุกอุปกรณ์** | ปัจจุบันระบบรองรับการออกจากระบบทีละเครื่อง หากต้องการความมั่นใจสูงสุดแนะนำให้เปลี่ยนรหัสผ่านใหม่ |
