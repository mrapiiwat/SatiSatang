# การสมัครสมาชิก

เริ่มต้นใช้งานสติสตางค์เพื่อจัดการการเงินของคุณได้อย่างง่ายดาย คุณสามารถเลือกสมัครสมาชิกได้หลายช่องทางตามความสะดวกของคุณ

### 1. กรอกข้อมูลการสมัคร
เข้าสู่หน้าสมัครสมาชิกและกรอกรายละเอียดดังนี้:
- **อีเมล:** ใช้อีเมลที่คุณใช้งานจริงเพื่อรับรหัสยืนยัน
- **รหัสผ่าน:** ตั้งรหัสผ่านที่ปลอดภัย (ควรมีความยาวอย่างน้อย 8 ตัวอักษร)
- **ยืนยันรหัสผ่าน:** กรอกรหัสผ่านเดิมอีกครั้งให้ตรงกัน
- **ชื่อ:** ระบุชื่อที่จะให้ระบบใช้เรียกคุณ

### สมัครผ่าน Google หรือ Facebook
คุณสามารถเลือกสมัครสมาชิกได้อย่างรวดเร็วโดยไม่ต้องกรอกข้อมูลและรหัสผ่านใหม่:

1. คลิกที่ปุ่ม **"ดำเนินการต่อด้วย Google"** หรือ **"ดำเนินการต่อด้วย Facebook"**
2. เข้าสู่ระบบผ่านบัญชีโซเชียลของคุณ
3. ยืนยันการอนุญาตให้สติสตางค์เข้าถึงข้อมูลพื้นฐาน (อีเมลและชื่อ)
4. ทำตามขั้นตอนการยอมรับเงื่อนไขในขั้นตอนสุดท้าย (เหมือนการสมัครด้วยอีเมล)

:::info ประโยชน์ของ Social Login
คุณไม่ต้องจำรหัสผ่านใหม่ และสามารถเข้าสู่ระบบได้ทันทีในครั้งถัดไปเพียงแค่คลิกเดียว
:::

## คำถามที่พบบ่อย (FAQs)

| คำถาม | คำตอบ |
| :--- | :--- |
| **รหัส OTP มีอายุการใช้งานนานเท่าไหร่?** | รหัส OTP จะมีอายุการใช้งาน 10 นาทีหลังจากที่ถูกส่ง |
| **ใช้ชื่อปลอมในการสมัครได้หรือไม่?** | ได้ แต่แนะนำให้ใช้ชื่อที่คุณต้องการให้แสดงในหน้าสรุปผลการเงิน |
| **เปลี่ยนอีเมลภายหลังได้ไหม?** | ปัจจุบันระบบยังไม่รองรับการเปลี่ยนอีเมลหลัก หากต้องการเปลี่ยนกรุณาติดต่อทีมงาน |
