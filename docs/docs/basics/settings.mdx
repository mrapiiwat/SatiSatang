# การจัดการบัญชีและตั้งค่า

สติสตางค์ช่วยให้คุณปรับแต่งการใช้งานให้เหมาะสมกับความต้องการส่วนตัวของคุณได้ง่ายๆ ผ่านหน้าการตั้งค่า

### วิธีเข้าสู่หน้าการตั้งค่า

1.  คลิกที่ปุ่มเมนู (สัญลักษณ์ขีดสามขีด) บริเวณมุมขวาบน
2.  เลือกเมนู **"การตั้งค่า"**

### 1. บัญชีผู้ใช้ (Account)

ในส่วนนี้คุณสามารถจัดการข้อมูลส่วนตัวพื้นฐานได้:
- **บัญชีผู้ใช้:** คลิกเพื่อแก้ไขชื่อที่แสดงในระบบ (Display Name) และดูอีเมลที่เชื่อมต่ออยู่
- **จัดการหมวดหมู่:** ปรับแต่งหมวดหมู่รายรับ-รายจ่ายของคุณให้ตรงกับไลฟ์สไตล์

### 2. การตั้งค่าแอป (App Settings)

คุณสามารถปรับแต่งการแสดงผลและระบบ AI ได้ที่นี่:
- **ภาษาแอป:** เลือกใช้งานระหว่างภาษาไทย และภาษาอังกฤษ
- **ภาษา AI:** เลือกภาษาที่ต้องการให้ "พี่สตางค์" สื่อสารกับคุณ
- **ธีม (Theme):** สลับระหว่างโหมดสว่าง (Light) และโหมดมืด (Dark) หรือตั้งค่าตามระบบ (System)
- **การแจ้งเตือน:** เปิด-ปิดการรับข้อมูลข่าวสารและการแจ้งเตือนสำคัญ
- **วันเริ่มต้นรอบงบประมาณ:** เลือกวันที่ต้องการให้ระบบรีเซ็ตยอดเงินในแต่ละเดือน (เช่น วันที่ 1 หรือวันที่เงินเดือนออก)

### 3. การสนับสนุน (Support)
- **ส่งความคิดเห็น:** หากคุณมีข้อเสนอแนะหรือพบปัญหา สามารถแจ้งเราได้ทันที
![ส่งความคิดเห็น](/img/screenshot/Screenshot%202569-04-28%20at%2021.40.20.png)
- **นโยบายความเป็นส่วนตัว:** อ่านรายละเอียดการปกป้องข้อมูลของคุณ

:::tip คำแนะนำ
หากคุณเปลี่ยนเครื่องที่ใช้งาน หรือเคลียร์แคชของเบราว์เซอร์ การตั้งค่าบางอย่าง (เช่น ธีม) อาจกลับไปเป็นค่าเริ่มต้น คุณสามารถเข้ามาปรับเปลี่ยนใหม่ได้เสมอครับ
:::
