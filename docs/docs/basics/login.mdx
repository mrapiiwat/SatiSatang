# การเข้าสู่ระบบ

เริ่มต้นการใช้งานสติสตางค์ด้วยขั้นตอนที่ง่ายและปลอดภัย เรามีช่องทางที่หลากหลายให้คุณเลือกใช้งานตามความต้องการ

![หน้าจอหลัก](/img/screenshot/Screenshot%202569-04-28%20at%2020.35.07.png)

## ช่องทางการเข้าใช้งาน

สติสตางค์รองรับการเข้าใช้งาน 3 รูปแบบหลัก เพื่อความสะดวกสูงสุดของคุณ

    ### การเข้าใช้งานด้วยอีเมล
    เหมาะสำหรับผู้ที่ต้องการความเป็นส่วนตัวและจัดการรหัสผ่านด้วยตนเอง:
    1. **ระบุอีเมล:** กรอกอีเมลของคุณในช่อง "อีเมล"

    1. คลิกที่ปุ่ม **"ดำเนินการต่อด้วย Facebook"**
    2. ยืนยันการเข้าใช้งานผ่านระบบของ Facebook
    3. เริ่มต้นบันทึกรายรับ-รายจ่ายได้ทันที

## ขั้นตอนการกู้คืนรหัสผ่าน (Forgot Password)

หากคุณจำรหัสผ่านไม่ได้ สติสตางค์มีระบบกู้คืนที่ปลอดภัยผ่านอีเมลของคุณ โดยมีขั้นตอนดังนี้:

### 1. ขอรับลิงก์รีเซ็ตรหัสผ่าน
ในหน้ากรอกรหัสผ่าน ให้คลิกที่ลิงก์ **"ลืมรหัสผ่าน? คลิกที่นี่"** (ตามกรอบสีแดงในรูป)

![หน้าจอกรอกรหัสผ่าน](/img/screenshot/Screenshot%202569-04-28%20at%2020.16.39.png)

เมื่อคลิกแล้ว ระบบจะแสดงหน้าต่างแจ้งว่าได้ส่งอีเมลไปให้คุณเรียบร้อยแล้ว

![หน้าต่างแจ้งเตือนส่งอีเมล](/img/screenshot/Screenshot%202569-04-28%20at%2020.00.15.png)

### 2. ตรวจสอบอีเมลของคุณ
เปิดกล่องจดหมายในอีเมลของคุณ คุณจะได้รับข้อความหัวข้อ "รีเซ็ตรหัสผ่านของคุณ" ให้คลิกที่ปุ่ม **"รีเซ็ตรหัสผ่าน"** หรือลิงก์ที่แนบมา

![ตัวอย่างอีเมลรีเซ็ตรหัสผ่าน](/img/screenshot/Screenshot%202569-04-28%20at%2020.03.02.png)

### 3. ตั้งรหัสผ่านใหม่
ระบบจะพาคุณมายังหน้าสำหรับกำหนดรหัสผ่านใหม่ ให้คุณกรอกรหัสผ่านที่ต้องการและกดยืนยัน

![หน้าตั้งรหัสผ่านใหม่](/img/screenshot/Screenshot%202569-04-28%20at%2020.05.06.png)

## คำถามที่พบบ่อย (FAQs)

| ปัญหา | วิธีแก้ไข |
| :--- | :--- |
| **ไม่ได้รับรหัส OTP/Email** | ตรวจสอบใน **จดหมายขยะ (Spam)** และตรวจสอบว่าสะกดอีเมลถูกต้องหรือไม่ |
| **ลิงก์รีเซ็ตรหัสผ่านหมดอายุ** | ลิงก์จะมีอายุการใช้งาน 5 นาที หากหมดอายุให้ทำรายการใหม่อีกครั้ง |
| **เข้าสู่ระบบ Google ไม่สำเร็จ** | ตรวจสอบว่าเบราว์เซอร์ของคุณอนุญาตการเปิดหน้าต่าง Pop-up หรือไม่ |

:::tip ข้อแนะนำ
เพื่อความปลอดภัย เราแนะนำให้คุณตั้งรหัสผ่านที่มีทั้งตัวอักษรและตัวเลขรวมกันอย่างน้อย 6 ตัวอักษรขึ้นไป
:::
