# พี่สตางค์

**พี่สตางค์** เป็นอีกหนึ่งระบบ AI Chat ของสติสตางค์ที่มาพร้อมกับฟังก์ชันพิเศษในการประมวลผลข้อความและการตอบกลับอย่างรวดเร็วด้วยการสตรีมมิ่งข้อมูล (Streaming Mode) เหมาะสำหรับการสนทนา สอบถามปัญหา หรือปรึกษาข้อมูลทางการเงิน

## จุดเด่นของพี่สตางค์

### 1. การสตรีมมิ่งคำตอบแบบเรียลไทม์ (Streaming Responses)
- เมื่อคุณพิมพ์ข้อความสอบถาม พี่สตางค์จะเริ่มแสดงคำตอบทีละตัวอักษรทันทีโดยไม่ต้องรอให้ประมวลผลเสร็จสิ้น ช่วยลดเวลาในการรอคำตอบได้อย่างมาก

### 2. การตอบคำถามเชิงลึก
- พี่สตางค์พร้อมให้คำแนะนำและตอบคำถามเกี่ยวกับพฤติกรรมการเงิน การวางแผน และการประหยัดค่าใช้จ่ายอย่างชาญฉลาด

---

## วิธีการใช้งานพี่สตางค์

1. เข้าสู่เมนู **"พี่สตางค์"** ผ่านระบบของสติสตางค์
2. พิมพ์คำถามหรือเรื่องที่ต้องการปรึกษา เช่น *"ช่วยแนะนำวิธีการเก็บเงิน 10,000 บาท ภายใน 3 เดือนหน่อยครับ"* หรือ *"ช่วยวิเคราะห์พฤติกรรมการใช้จ่ายของเดือนที่ผ่านมาให้หน่อย"*
3. พี่สตางค์จะเริ่มพิมพ์คำตอบและให้คำแนะนำแบบเรียลไทม์

:::tip ข้อแนะนำ
คุณสามารถใช้งานทั้งน้องสติ (เพื่อช่วยบันทึกข้อมูลและธุรกรรมอัตโนมัติ) และพี่สตางค์ (เพื่อพูดคุยสอบถามและวางแผนการเงิน) ควบคู่กันไปเพื่อประสิทธิภาพสูงสุดในการจัดการการเงินของคุณ
:::
