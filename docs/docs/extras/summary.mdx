# สรุปรายรับรายจ่าย

หน้าจอ **สรุปรายรับรายจ่าย (Summary)** เป็นศูนย์รวมข้อมูลทางการเงินเพื่อวิเคราะห์พฤติกรรมการใช้จ่าย บรรลุเป้าหมาย และส่งต่อสรุปการเงินของคุณ

![สรุปรายรับรายจ่าย](/img/mockup/17.1_Summary.png)

</div>

## ส่วนประกอบของหน้าสรุปรายรับรายจ่าย

### 1. ส่วนเลือกเดือนและปี (Month Header)
- แสดงแถบเลือกเดือนและปีที่ด้านบนสุดของหน้าจอ
- สามารถกดปุ่มลูกศรซ้าย-ขวาเพื่อเลื่อนดูสรุปของเดือนก่อนหน้าหรือเดือนถัดไปได้อย่างง่ายดาย

<div style={{ width: '70%', maxWidth: '300px', margin: '0 auto', display: 'block' }}>

![เลือกเดือนและปี](/img/mockup/17.2_Summary_Date_Picker.png)

</div>

### 2. กราฟวงกลมสรุปสัดส่วน (Pie Chart)
- **รายรับ (Income):** แสดงด้วยสีม่วงเข้ม (`#5300E8`)
- **รายจ่าย (Expense):** แสดงด้วยสีชมพู (`#E278FA`)
- **เป้าหมาย (Goal):** แสดงด้วยสีเขียวมะนาว (`#C8E84D`)
- มีการคำนวณสัดส่วนคิดเป็นเปอร์เซ็นต์อัตโนมัติอยู่ตรงกลางของกราฟวงกลม

<div style={{ width: '70%', maxWidth: '300px', margin: '0 auto', display: 'block' }}>

![กราฟวงกลมสรุปสัดส่วน](/img/mockup/17.1_Summary.png)

</div>

### 3. การ์ดแสดงข้อมูลเชิงลึก
- **รายรับทั้งหมด:** แสดงยอดเงินรายรับรวมประจำเดือน พร้อมปุ่ม "ดูเพิ่มเติม" เพื่อดูรายการรายรับทั้งหมด
- **รายจ่ายทั้งหมด:** แสดงยอดเงินรายจ่ายรวมประจำเดือน พร้อมปุ่ม "ดูเพิ่มเติม" เพื่อดูรายการรายจ่ายทั้งหมด
- **เป้าหมาย:** แสดงยอดการออมเงินเพื่อเป้าหมายต่างๆ ประจำเดือน พร้อมปุ่ม "ดูเพิ่มเติม" เพื่อดูเป้าหมายแต่ละรายการ

## ฟังก์ชันการแบ่งปันและส่งออก

คุณสามารถบันทึกสรุปข้อมูลทางการเงินของคุณหรือส่งต่อให้ผู้อื่นได้ผ่าน 2 ฟังก์ชันหลักด้านล่างหน้าจอ:

### 1. ปุ่มแชร์ (Share)
- กดปุ่ม **"แชร์"** ระบบจะทำการแปลงหน้าจอสรุปรายรับรายจ่ายให้เป็นรูปภาพ
- หากเบราว์เซอร์ของคุณรองรับ คุณสามารถส่งต่อรูปภาพสรุปนี้ผ่าน Social Media หรือบันทึกเก็บไว้ได้ทันที

### 2. ปุ่มดาวน์โหลด (Download)
- กดปุ่ม **"ดาวน์โหลด"** ระบบจะจับภาพหน้าจอสรุปทางการเงินเป็นรูปภาพ `.png`
- ทำการดาวน์โหลดลงเครื่องของคุณโดยอัตโนมัติ เพื่อเก็บเป็นหลักฐานหรือบันทึกข้อมูลการเงินรายเดือน

<div style={{ width: '70%', maxWidth: '300px', margin: '0 auto', display: 'block' }}>

![ปุ่มแชร์และปุ่มดาวน์โหลด](/img/mockup/17.4_Share_Dowload.png)

</div>
