# จัดการหมวดหมู่

การจัดหมวดหมู่ที่เหมาะสมเป็นสิ่งสำคัญที่จะช่วยให้คุณวิเคราะห์ข้อมูลทางการเงินได้อย่างมีประสิทธิภาพ หน้าจอ **จัดการหมวดหมู่ (Categories)** ช่วยให้คุณเพิ่ม แก้ไข หรือลบหมวดหมู่ของรายรับและรายจ่ายได้ตามต้องการ

---

## ส่วนประกอบของหน้าจัดการหมวดหมู่

### 1. แถบประเภทหมวดหมู่ (Category Header)
- **รายรับ (INCOME):** แสดงรายการหมวดหมู่สำหรับรายรับ
- **รายจ่าย (EXPENSE):** แสดงรายการหมวดหมู่สำหรับรายจ่าย
- คุณสามารถคลิกเพื่อสลับระหว่างสองประเภทนี้ หรือปัดซ้าย-ขวาบนหน้าจอเพื่อสลับหน้าได้อย่างรวดเร็ว

### 2. รายชื่อหมวดหมู่ (Category List)
- แสดงชื่อหมวดหมู่และไอคอนที่เกี่ยวข้อง
- **ปุ่มเพิ่มหมวดหมู่:** สำหรับเพิ่มหมวดหมู่ใหม่ในประเภทที่คุณกำลังเลือกอยู่

---

## วิธีการจัดการหมวดหมู่

### 1. การเพิ่มหมวดหมู่ใหม่
- คลิกที่ปุ่ม **"เพิ่มหมวดหมู่"**
- ใส่ชื่อหมวดหมู่ที่ต้องการ
- เลือกไอคอนและสีที่สื่อความหมายสำหรับหมวดหมู่นั้นๆ
- กดปุ่มบันทึก

<div style={{ width: '70%', maxWidth: '300px', margin: '0 auto', display: 'block' }}>

![ปุ่มเพิ่มหมวดหมู่](/img/mockup/13.3_Add_New_Categories.png)

</div>

### 2. การแก้ไขหมวดหมู่
- คลิกที่หมวดหมู่ที่คุณต้องการแก้ไข
- ปรับเปลี่ยนชื่อ ไอคอน หรือสี
- กดปุ่มบันทึกการเปลี่ยนแปลง

<div style={{ width: '70%', maxWidth: '300px', margin: '0 auto', display: 'block' }}>

![การแก้ไขหมวดหมู่](/img/mockup/13.4_Edit_Categories.png)

</div>
### 3. การลบหมวดหมู่
- คลิกที่หมวดหมู่ที่ต้องการลบ
- กดปุ่มลบ (ลบได้เฉพาะหมวดหมู่ที่คุณสร้างขึ้นเอง และไม่มีรายการธุรกรรมที่เชื่อมโยงอยู่)

<div style={{ width: '70%', maxWidth: '300px', margin: '0 auto', display: 'block' }}>

![การลบหมวดหมู่](/img/mockup/13.5_Delete_Categories_point.png)

</div>

:::tip ข้อแนะนำ
สร้างหมวดหมู่ที่เหมาะสมกับพฤติกรรมการเงินของคุณ เพื่อให้การแสดงผลในหน้าสรุปรายรับรายจ่าย (Summary) มีความถูกต้องและเป็นประโยชน์สูงสุด
:::
