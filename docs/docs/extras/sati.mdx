# น้องสติ

**น้องสติ** คือผู้ช่วย AI สุดอัจฉริยะที่จะคอยช่วยเหลือคุณในการจัดการการเงิน ไม่ว่าจะเป็นการบันทึกข้อมูล การตั้งงบประมาณ หรือการตั้งเป้าหมาย ผ่านการพิมพ์ข้อความหรือพูดคุยได้อย่างเป็นธรรมชาติ

---

## ฟังก์ชันการทำงานของน้องสติ

### 1. บันทึกรายการรายรับรายจ่ายอัตโนมัติ
- คุณสามารถบอกให้น้องสติบันทึกรายการได้ทันที เช่น
  - *"กินข้าวไป 80 บาท"*
  - *"ได้รับเงินเดือน 30,000 บาท"*
- น้องสติจะทำการแปลงข้อความของคุณให้เป็นข้อมูลธุรกรรมที่ถูกต้อง (ระบุจำนวนเงิน, วันที่, และเลือกหมวดหมู่ให้โดยอัตโนมัติ) และสร้าง **"การ์ดยืนยัน"** ขึ้นมาให้คุณกดบันทึกหรือยกเลิก

![บันทึกรายการรายรับรายจ่าย](/img/screenshot/Screenshot%202569-05-03%20at%2012.55.29.png)

### 2. ตั้งงบประมาณ (Set Budget)
- คุณสามารถสั่งตั้งงบประมาณผ่านน้องสติ เช่น *"ตั้งงบค่าอาหารเดือนนี้ 5,000 บาท"*
- น้องสติจะสร้างโครงร่างงบประมาณให้คุณตรวจสอบและกดยืนยัน

![ตั้งงบประมาณ](/img/screenshot/Screenshot%202569-05-03%20at%2012.56.48.png)

### 3. ตั้งเป้าหมายออมเงิน (Set Goal)
- คุณสามารถบอกเป้าหมายของคุณ เช่น *"ตั้งเป้าหมายซื้อโทรศัพท์ใหม่ 35,000 บาท ภายในสิ้นปีนี้"*
- น้องสติจะคำนวณและแสดงผลการตั้งเป้าหมายให้คุณกดยืนยันเพื่อเริ่มออมเงินได้ทันที

![ตั้งเป้าหมายออมเงิน](/img/screenshot/Screenshot%202569-05-03%20at%2012.58.40.png)

## ขั้นตอนการใช้งาน

1. กดปุ่ม **"น้องสติ"** (ปุ่มแชตสีฟ้า) ที่มุมล่างขวาของหน้าหลัก
2. พิมพ์ข้อความสิ่งที่คุณต้องการให้น้องสติช่วยเหลือ
3. ตรวจสอบการ์ดข้อมูลที่น้องสติสร้างขึ้น
4. กดปุ่ม **"ตกลง"** เพื่อบันทึกข้อมูล หรือ **"แก้ไข"** หากข้อมูลยังไม่ถูกต้อง

:::tip ข้อแนะนำ
น้องสติช่วยให้การบันทึกการเงินเป็นเรื่องสนุกและง่ายดายขึ้น ไม่จำเป็นต้องกดเลือกหลายขั้นตอน เพียงแค่บอกน้องสติเท่านั้น!
:::
